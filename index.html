About this site / Kantudongqian Uploader

Kantudongqian (看片懂錢) is a Traditional Chinese YouTube channel that explains Taiwan's economy and personal finance with animated data charts.

"Kantudongqian Uploader" is a private, internal tool used only by the channel owner. It uses the YouTube Data API to upload the channel's own videos and set their title, description, tags, thumbnail, captions, synthetic-media disclosure and publish schedule. It does not access, collect or display data of any other YouTube user.
